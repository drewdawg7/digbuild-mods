# Alex's Caves — Blocks & Items

Grouped by the mod's own creative tabs, extracted from `ACCreativeTabRegistry`.
This is the mod author's grouping and the order players see in-game, so it is the
right skeleton for wiki category pages.

IDs are all in the `alexscaves:` namespace. A few entries appear in more than one
tab (the shared progression items: `cave_tablet`, `cave_codex`, `cave_book`,
`spelunkery_table`), which is intentional — every biome tab leads with them.

> **IDs are the real registry names**, read from the `register("…")` calls in
> `ACBlockRegistry` / `ACItemRegistry` / `ACEffectRegistry` — not guessed from the
> Java field names, which frequently differ. For example the field `WHITE_ROCK_CANDY`
> registers as `rock_candy_white`, `NOTOR_COMPONENT` as `notor_gizmo`,
> `PEWEN_PLANKS_STAIRS` as `pewen_stairs`, and `MUSIC_DISC_TASTY_FRAGMENT` as
> `disc_fragment_tasty`. Use these IDs verbatim in commands and datapacks.

Only one custom recipe type ships as data (`alexscaves:cave_map`); the special
workstations — Spelunkery Table, Confection Oven, Conversion Crucible, Nuclear
Furnace — are code-driven block entities rather than datapack recipe types.

The **Nuclear Furnace** is configurable: on this server `nuclear_furnace_blasting_only`
is `true` (uses only blasting recipes) and `nuclear_furnace_custom_type` is `false`
(does not restrict itself to an `alexscaves:nuclear_furnace` recipe type). Both are
defaults. If you ever want pack-specific nuclear furnace recipes, flipping the second
to `true` is the hook.
